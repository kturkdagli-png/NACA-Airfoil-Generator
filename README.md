# NACA Airfoil Generator

This project generates NACA 0012 and NACA 2412 airfoil coordinates using C++.

## Features

- NACA 0012 and NACA 2412 airfoil generation
- Cosine spacing for point distribution
- 100 points used to define the airfoil
- Airfoil coordinates exported as `.dat` files

## Tools

- C++
- XFLR5

## Project

The generated airfoil coordinates can be imported into XFLR5 for aerodynamic analysis.

This project was developed as part of my aerospace engineering studies.
